Que es?

Un programa de consola desarrollado en C para resolver ejercicios de cinemática.

Caracteristicas:

  • Resolución de MRU
  • Resolución de MRUA
  • Problemas de alcance MRU-MRUA
  • Menus interactivos
  • Bugs muy locos (aveces).
